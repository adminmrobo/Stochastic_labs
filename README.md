# 확률해석 교실 — 불확실한 세상의 미적분

중학생도 따라올 수 있게 만든 확률해석(확률미적분) 연구실 해설 시리즈예요. 인포그래픽 10장(Stochastic Analysis — Calculus under uncertainty)에 담긴 아홉 주제 — 확률과정, 필트레이션, 브라운 운동, 마팅게일, 이토 적분, 이토 공식, 확률미분방정식, 포커-플랑크 방정식, 정지시간 — 를 13장으로 나누고, 장마다 다른 수업 형식(1:1 토론, 역할극, 조별 과제, 계산배틀, 찬반 토론, 발표수업, 조별 토론, 쪽지시험)으로 풀었어요. 행렬·벡터는 한 번도 나오지 않아요.

- 선생님: 박사 · 조교: 초파리 연구원, 주판봇 · 수강생: 인턴 시아, 인턴 모아, 조수 하루, 미공개 X1·X2·X3
- 1조 「동전조」 시아·하루·X1 / 2조 「주사위조」 모아·X2·X3

**바로 보기:** https://adminmrobo.github.io/stochastic_labs/ (GitHub Pages를 켜면 열려요)

## 구성

- `index.html`, `NN_*.html`, `practice/index.html` — 페이지 (외부 라이브러리 없음, 글꼴만 외부 요청, 브라우저 저장소 사용 안 함)
- `assets/` — 공용 스타일(`lab.css`), 캐릭터·용어·퀴즈·대결(`lab.js`), 그림 실험(`widgets.js` ← `assets/src/w1~w3.js`), 실전 연습장(`practice.js`), 캐릭터 그림(`sprites.js`), 지식 색인·꾸러미(`js/kgx.js`)
- `content/` — 장별 내용 데이터, `tools/build.py` — 조립 스크립트 (`python3 tools/build.py`), `tools/check_numbers.py` — 예시 숫자 검산
- `img/source/` — 원자료 인포그래픽 10장(사용자 제공), `img/og/` — 공유 미리보기
- `docs/IMG_specs.md` — 표지 15장·장면 26장 픽셀아트 지시문(16비트 RPG), `docs/WORK_NOTES.md` — 사실 카드·원자료 바로잡기·검산·교수법 채점 기록, `docs/PERSONA_REVIEW.md` — 페르소나 검사
- `cover_manifest.json` — 표지·온톨로지 현황판 연결 파일

원자료 인포그래픽에서 바로잡은 곳(±√t 띠의 뜻, 마팅게일의 적합 조건, 이토 등거리의 조건, 표류 기호 μ·b, 첫 도달 시간 τ = ∞)은 각 단계의 「원자료 인포그래픽 보기」 상자와 `docs/WORK_NOTES.md`에 「원자료의 A를 이 페이지에서는 B로 바꿉니다」 형식으로 적었어요.
