√t 법칙과 이차변동 — 브라운 운동의 두 계산

핵심 질문 — 시간이 4배가 되면 브라운 운동은 몇 배 퍼질까? 그리고 「조각 제곱의 합」은 왜 시간과 같을까?

브라운 운동에서 가장 자주 쓰는 계산 두 개를 배워요. 하나는 √t 법칙 — 퍼짐(표준편차)은 시간이 아니라 시간의 제곱근으로 커져요. 다른 하나는 이차변동 — 경로를 잘게 나눠 높이 차이를 제곱해 더하면 시간 t가 돼요. 이 두 번째 계산이 08장 이토 공식의 「덤」을 만들어요.

2배시간 4배일 때 퍼짐의 배수 (√4)
68%±√t 띠 안에 있는 경로 비율
[W]ₜ = t브라운 운동의 이차변동
0매끄러운 곡선의 이차변동

숫자 요약은 이 장의 예시 계산에서 나온 값입니다(실제 데이터가 아닌 설명용 값).

처음 오신 분께 — 이 페이지를 3줄로

  1. 무엇을: 브라운 운동의 퍼짐이 √t로 커지는 이유(√t 법칙)와, 잘게 나눈 높이 차이의 제곱합이 t에 모이는 성질(이차변동 [W]ₜ = t)을 직접 계산해 봅니다.
  2. 왜 중요한가: √t 법칙은 「오래 기다릴수록 예측 범위가 얼마나 넓어지나」를, 이차변동은 「왜 보통 미적분 공식에 덤이 붙나」(08장)를 설명해요.
  3. 생활·현장에서는: 금융에서 「1년 변동성 20%면 하루 변동성은 20% ÷ √252 ≈ 1.3%」처럼 기간을 바꿀 때 바로 √t 법칙을 써요.

행렬·벡터, 복잡한 공식을 몰라도 됩니다. 그림을 움직여 보고, 밑줄 친 말을 누르면 뜻이 나옵니다.

영어 기호·약어 풀이 (펼치기)
  • √t — 루트 t — 제곱해서 t가 되는 수
  • [W]ₜ — W의 이차변동(quadratic variation) — 조각 높이 차이 제곱의 합의 극한
  • Σ (시그마) — 「모두 더한다」는 기호
  • ΔW — 델타 W — 짧은 구간의 높이 차이

1

1단계 · √t 법칙 — 시간 4배면 퍼짐은 2배

방법: 표준편차 = √t일상: 잉크 방울 번짐
박사

상황 질문 — 일기 예보에서 「내일 기온은 ±2도, 일주일 뒤는 ±몇 도」일까요? 날짜가 7배면 오차도 7배일까요?

왜 이 방법을 쓰나

  1. 문제 상황: 기간이 늘 때 예측 범위가 얼마나 넓어지는지 알고 싶어요.
  2. 앞 방법의 한계: 「시간에 비례해서 넓어진다」고 짐작하면 오래 뒤 위험을 크게 부풀려요.
  3. 해법: 분산이 t에 비례하므로 표준편차는 √t에 비례해요. 시간 4배 → 퍼짐 2배, 100배 → 10배.
쉽게 말하면 — 퍼짐은 시간을 따라가지만, 제곱근만큼 느리게.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

분산은 t인데 왜 퍼짐은 √t예요? 둘이 같은 거 아니에요?

학교 수학으로 보면: 01장의 「표준편차 = √분산」이에요. 분산은 「거리의 제곱」 단위라서, 원래 단위의 퍼짐으로 돌아오려면 √를 씌워요.

식 조각읽는 법뜻
Var(W(t)) = t분산 더블유 티는 티04장의 증분 성질에서 (0부터 t까지의 증분)
SD = √t표준편차는 루트 티원래 단위의 퍼짐
±√t 띠플러스마이너스 루트 티경로의 약 68%가 들어 있는 범위 (울타리가 아님)
숫자로 한 번 해 보기

t = 1: 표준편차 1

t = 4: 표준편차 √4 = 2 (시간 4배, 퍼짐 2배)

t = 9: 표준편차 3

연 변동성 20%, 1년 252거래일 → 하루 변동성 20% ÷ √252 ≈ 1.26%

조수 하루 (수강생)

시간은 1, 4, 9인데 퍼짐은 1, 2, 3. 시간을 「제곱수」로 고르면 퍼짐이 정수로 딱 떨어지네요!

일상으로 치면

물에 떨어뜨린 잉크 방울은 처음엔 빨리 번지다가 점점 느리게 번져요. 번진 반지름이 시간에 비례하지 않고 제곱근에 비례해서 그래요(아인슈타인, 1905).

확률해석에서는

브라운 운동의 표준편차는 √t예요. 원자료 왼쪽 그림의 점선 ±√t가 이 띠예요. 단, 띠는 1표준편차 범위라 경로의 약 68%만 안에 있어요.

박사

1라운드! 시각 막대를 1, 4, 9로 옮기며 표준편차와 √t를 비교하세요. 띠 안 비율도 보고요.

주판봇

시간이 4배면 퍼짐도 4배! 정직하게 비례하죠.

초파리 연구원

t = 1과 t = 4의 표준편차를 나눠 봐. 4가 나와?

1라운드 — ±√t 띠와 경로 200개

풀이 — 한 걸음씩

  1. t = 1, 4, 9에서 경로 200개의 표준편차가 약 1, 2, 3이에요. √t와 거의 같아요.
  2. 초록 띠(±√t) 안에는 경로의 약 68%만 있어요. 나머지 32%는 띠 밖으로 나가요.
  3. 띠 너비를 ±2√t로 넓히면 약 95%가 안에 들어와요.
  4. 그래서 ±√t 띠는 「울타리」가 아니라 「대부분이 있는 곳」이에요.
이 단계의 한계 — 68%·95%는 정규분포일 때의 비율이에요. 실제 주가처럼 가끔 크게 튀는 데이터는 띠 밖으로 나가는 비율이 더 클 수 있어요.
박사의 해석 — 「1년 뒤 주가 범위」를 말할 때 √t 법칙을 쓰면, 하루 위험의 약 16배(√252)가 1년 위험이에요. 252배가 아니에요.
원자료 인포그래픽 보기 (영어 그림)

원자료 「3 · Brownian motion」 왼쪽의 점선 ±√t와 경로들. 원자료 그림에서는 경로가 모두 점선 안에 있지만, 실제로는 약 32%가 밖으로 나가요.

원자료 그림의 ±√t 점선은 경로가 넘지 못하는 경계처럼 보여요. 이 페이지에서는 「±√t는 1표준편차 범위라 경로의 약 68%만 안에 있다」로 바꿉니다.
2

2단계 · 이차변동 — 조각 제곱의 합은 t

방법: Σ(ΔW)² → t일상: 꼬불꼬불 길의 흔들림 총량
박사

상황 질문 — 자동차 계기판에 「오늘 핸들을 얼마나 흔들었나」를 재는 장치가 있다면, 매끄러운 고속도로와 자갈길은 어떻게 다르게 나올까요?

30초 복습 — Σ (시그마) 기호
Σ는 「모두 더한다」는 뜻이에요. Σ(조각 높이 차이)²은 「조각마다 높이 차이를 제곱해서 전부 더한 것」. 1² + 2² + 3² = 14처럼 손으로 더하는 것과 같아요.

왜 이 방법을 쓰나

  1. 문제 상황: 경로가 「얼마나 거칠게 흔들렸나」를 숫자 하나로 재고 싶어요.
  2. 앞 방법의 한계: 높이 차이를 그냥 더하면 위아래가 지워지고, 절댓값을 더하면 잘게 나눌수록 끝없이 커져요.
  3. 해법: 높이 차이를 제곱해서 더해요(Σ(ΔW)²). 매끄러운 곡선은 0으로, 브라운 운동은 시간 t로 모여요.
쉽게 말하면 — 흔들림의 「제곱 총량」 — 매끄러우면 0, 브라운 운동이면 시간만큼.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

Σ(ΔW)²가 왜 하필 t가 돼요? 우연인데 딱 떨어지는 게 이상해요.

학교 수학으로 보면: 04장의 「증분의 분산 = 시간 간격」이에요. (ΔW)²의 평균이 Δt이니, 조각 n개를 더하면 평균 n × Δt = t. 조각이 많을수록 우연이 서로 상쇄돼 평균에 붙어요.

식 조각읽는 법뜻
ΔWᵢ = W(tᵢ₊₁) − W(tᵢ)델타 더블유 아이i번째 조각의 높이 차이
Σ (ΔWᵢ)²시그마 델타 더블유 아이 제곱조각 높이 차이 제곱을 모두 더한 것
[W]ₜ = t더블유의 이차변동은 티조각을 끝없이 잘게 하면 제곱합이 t로 모임
숫자로 한 번 해 보기

[0, 1]을 n = 4조각, 각 Δt = 0.25 → (ΔW)² 평균 0.25 → 합 평균 4 × 0.25 = 1

n = 4096이면 합이 1 근처에 거의 딱 붙어요(흔들림 작아짐)

매끄러운 y = t: ΔW = Δt = 1/n → 합 n × (1/n)² = 1/n → 0

브라운 운동은 1, 매끄러운 선은 0

조수 하루 (수강생)

제곱하면 브라운 운동의 높이 차이(√Δt)가 Δt가 되니까, 더하면 딱 시간 길이가 되는 거네요!

일상으로 치면

고속도로에서는 핸들을 아주 조금씩만 움직여 「흔들림 제곱 총량」이 거의 0이에요. 자갈길에서는 짧게 잘라 봐도 매번 흔들려서 총량이 운전 시간에 비례해 쌓여요.

확률해석에서는

조각 제곱합의 극한을 이차변동이라 해요. 브라운 운동은 [W]ₜ = t, 매끄러운 곡선은 0이에요. 짧게 쓰면 (dW)² = dt — 08장 이토 공식의 핵심 규칙이에요.

박사

초파리 연구원

브라운 운동으로 두고 n = 4096을 봐. 0이 맞아?

2라운드 — 조각 제곱합 Σ(ΔW)²

풀이 — 한 걸음씩

  1. 브라운 운동: n = 4에서는 제곱합이 들쭉날쭉하지만, n을 키울수록 1(= 시간 길이)에 붙어요(오른쪽 그래프).
  2. 절댓값 합은 n을 키울수록 계속 커져요. 그래서 「길이」로는 흔들림을 잴 수 없어요.
  3. 매끄러운 곡선: n을 키울수록 제곱합이 0으로 사라져요.
  4. 조각을 아무리 작게 해도 브라운 운동의 (ΔW)²는 Δt만큼 남아요 → (dW)² = dt.
이 단계의 한계 — 이차변동이 「정확히 t」인 것은 조각을 끝없이 잘게 한 극한에서예요. 그림처럼 n이 유한하면 t 둘레에서 조금 흔들려요.
박사의 해석 — 실제 데이터에서 Σ(수익률)²을 「실현 변동성」이라 부르며 시장의 거친 정도를 재요. 오늘의 계산이 그 근거예요.
원자료 인포그래픽 보기 (영어 그림)

원자료 오른쪽 아래 「Quadratic variation: [W]ₜ = t」.

더 알고 싶은 분께 — 정확한 정의 (몰라도 됩니다)

[0, t]의 분할 0 = t₀ < … < tₙ = t에서 분할 간격이 0으로 갈 때 Σ(W(tᵢ₊₁) − W(tᵢ))² → t (L² 수렴, 확률 수렴). 매끄러운(유계 변동) 함수의 이차변동은 0이다.

AI 판단 코너 — AI가 낸 답, 그대로 믿어도 될까?

시아가 AI에게 「하루 주가 변동성이 1%라면 1년(252거래일) 변동성은?」이라고 물었더니 이렇게 답했어요.

AI 답변: 하루 1%가 252일 쌓이므로 1년 변동성은 1% × 252 = 252%입니다. 주가가 1년에 2.5배 넘게 흔들릴 수 있습니다.
