# 페르소나 검사 — 확률해석 교실 (2026-11-25)

검사 기준 독자: 수학이 너무 어렵고, 특히 행렬·벡터를 처음 공부하는 학생. 평가 대상은 13장 + 실전 연습장 + 목차 페이지(자기 결과물이라 문제점 위주로 봄).

## 0. 대상 요약
인포그래픽 10장의 아홉 주제를 13장으로 나눈 연구실 해설 시리즈. 장마다 3줄 요약 → 수업 형식 → 큰 그림 → 2~3단계(상황 질문, 왜 이 방법, 조수 수식 상자, 그림 실험, 풀이, 퀴즈) → AI 판단 → 조교 대결 → 정리 순서. 행렬·벡터는 한 번도 쓰지 않고 모든 과정을 1차원으로 설명한다. 마지막 장은 사업장 네 곳의 시뮬레이터(미션 12개).

## 5. 정리
입문 쪽(A·B)은 「행렬·벡터 없이 동전과 그림만으로」라는 출발에는 높은 점수를 줬지만, 수식 상자가 기대는 고등학교 개념(기울기, Σ, 편미분)이 복습 없이 나오는 몇 곳에서 점수가 깎였다. 실무·교육 쪽(C·D·F)은 계산 판정형 대결과 실전 연습장의 쓸모를 높게 봤고, 부족한 점은 분량·활동지·응용 예 같은 「더 있으면 좋은 것」이었다. 전문가(E)는 조건을 챙긴 점을 인정했지만 12장의 틀린 문장 하나를 찾았다. 그래서 정확성 오류(1순위)와 입문 독자가 막히는 세 곳의 복습(2·3순위)을 먼저 고쳤다.
