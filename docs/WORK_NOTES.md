# 작업 메모 — 확률해석 교실 (stochastic_labs)

- 독자 진단: 주 독자를 정하지 않아 **혼합형**으로 가정 (수식 막힘 처방 먼저, 해석 연습은 뒤에).
- 주 독자 한 줄: 확률해석을 처음 보는 중학생, 행렬·벡터도 아직 배우는 중인 학생.
- 원자료: 사용자가 준 인포그래픽 10장 (`img/source/src01~10.webp`, @eeanimation 표기). 작성자·연도 확인 필요 — 꾸러미에서 「확인 필요」.
- 원자료와 다른 값은 저자 확인 전 기본값대로 「원자료의 A를 이 페이지에서는 B로 바꿉니다」로 표기.
- 분야: 수학·통계(확률해석) 주 분야, 금융·물리·AI(확산 모델) 응용 보조. 비유 앵커는 D(일상).
- 행렬·벡터: 13장 전체에서 한 번도 쓰지 않음(모두 1차원 과정으로 설명). 페르소나 검사 기준 독자에 맞춤.

## 사실 카드 — 원자료와 다른 곳 (검산·확정)
| # | 원자료 | 이 페이지 | 근거 |
|---|---|---|---|
| F1 (src04) | ±√t 점선 안에 경로가 모두 있는 것처럼 그림 | ±√t는 1표준편차 범위, 경로의 약 68%만 안 (05장) | 정규분포 Φ(1) − Φ(−1) = 0.683 |
| F2 (src05) | 마팅게일 조건 두 개 (E|Mₜ| < ∞, E[Mₜ|𝓕ₛ] = Mₛ) | 「Mₜ가 𝓕ₜ-가측(적합)」 조건을 더해 세 개 (06장) | Williams (1991) |
| F3 (src06) | 이토 등거리를 조건 없이 적음 | 「H 적합, E∫H² dt < ∞」 조건을 붙임 (07장) | Øksendal (2003) |
| F4 (src01·src08) | 표지는 표류 μ, 7번 그림은 b(Xₜ, t) | 상수일 때 μ, 일반형 b로 구별 (09장) | 기호 정리 |
| F5 (src10) | 닿지 않는 경로를 τₐ > T로만 표시 | 닿는 시각이 없으면 τₐ = ∞로 정의 (11장) | inf ∅ = ∞ 관례 |
| F6 (src07) | 이토 공식에 f의 매끄러움 조건 없음 | 「더 알고 싶은 분께」에 f ∈ C^{1,2} 명시 (08장) | Øksendal (2003) |

## 검산한 숫자 (`tools/check_numbers.py`)
- 주사위 평균 3.5, 분산 2.917 · 동전 100번 정확히 50번 7.96% · 10걸음 끝 0일 확률 24.6% (252/1024)
- ±1표준편차 68.3%, ±2표준편차 95.4% · 100걸음 뒤 |위치| ≤ 10 약 72.9%
- ∫₀¹ W dW 왼쪽 끝 합 평균 ≈ 0, 가운데 합 평균 ≈ 0.5, 이차변동 평균 ≈ 1.00 (경로 4000개) · 이토 등거리 E[(∫W dW)²] ≈ 0.496 (이론 0.5)
- E[e^W(1)] = e^0.5 ≈ 1.649 · 주가 모형(μ 0.1, σ 0.3, 4년) 평균 100e^0.4 ≈ 149, 가운데 100e^0.22 ≈ 125
- 도박사의 파산 k = 3, N = 10 → 30% · 앞면 0.47 동전 k = 5, N = 10 → 35.4% · 배가 전략 기대값 0
- 반사 원리 P(τ₁ ≤ 1) = 2(1 − Φ(1)) ≈ 31.7% · a = 3, T = 4 → 13.4% · a = 1.5, T = 4 → 45.3%
- 평균 회귀 평형 표준편차 σ/√(2θ): σ = 1, θ = 2 → 0.5 · dX = 1 dt + 2 dW, t = 4 → 평균 4, 표준편차 4
- 실전 연습장 최적값: 주식 μ 8%·σ 0.2의 손실 20% 미만 최단 보유 8년(7년 21.4%, 8년 19.8%), 잉크 공장 b 0.5·σ 1 센서 최고 농도 시각 약 8.2분, 정수기 σ 1 최적 θ ≈ 1.5 (σ 1.5 → 2.15)
