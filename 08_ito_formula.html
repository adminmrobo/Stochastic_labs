이토 공식 — 연쇄법칙에 붙는 덤

핵심 질문 — W가 조금 변할 때 f(W)는 얼마나 변할까? 보통 미분 공식대로 될까?

보통 미적분의 연쇄법칙은 「f(x)의 변화 ≈ f′ × x의 변화」예요. 2차 조각 (Δx)²은 너무 작아서 버려요. 그런데 브라운 운동은 05장에서 봤듯 (ΔW)² 의 합이 시간 t로 남아요. 그래서 버리던 2차 조각이 「½f″ dt」라는 덤으로 살아나요. 이것이 이토 공식, 확률적 연쇄법칙이에요.

(dW)² = dt이토 공식의 핵심 규칙
½σ²f″보통 연쇄법칙에 붙는 덤
e^(t/2)E[e^W(t)] — 덤 때문에 1이 아님

  2. 왜 중요한가: 이토 공식은 확률해석에서 가장 많이 쓰는 계산 도구예요. 09장 확률미분방정식 풀기, 주가 모형의 평균과 가운데 값, 블랙-숄즈 옵션 가격식이 모두 이 공식에서 나와요.

상황 질문 — 한 변이 1m인 정사각형 땅의 변을 조금 늘리면 넓이는 얼마나 늘까요? 「아주 조금」 늘리면 무엇을 무시해도 될까요?

왜 이 방법을 쓰나

  1. 문제 상황: 함수 f(x)가 x의 작은 변화에 어떻게 반응하는지 계산하고 싶어요.

조수 하루 (수강생)

(1 + Δx)² 을 펼치면 왜 조각이 세 개 나와요?

학교 수학으로 보면: 중학교 「곱셈 공식」 (a + b)² = a² + 2ab + b² 이에요. 1² + 2×1×Δx + (Δx)² 에서 (Δx)²이 2차 조각이에요.

Δf = 2x·Δx + (Δx)²델타 에프f(x) = x²의 실제 변화 (1차 + 2차 조각)
f′(x)Δx1차 조각연쇄법칙이 남기는 부분
(Δx)² ÷ Δt → 02차 조각 나누기 델타 티매끄러운 길이면 0으로 사라짐 → 버림
숫자로 한 번 해 보기

x = 1, 매끄러운 길 x(t) = t, Δt = 0.1 → Δx = 0.1

실제 변화 1.1² − 1 = 0.21, 1차 조각 2 × 0.1 = 0.2, 2차 조각 0.01

Δt = 0.01: 2차 조각 0.0001, 2차 조각 ÷ Δt = 0.01

Δt를 10배 줄이면 2차 조각 ÷ Δt도 10배 줄어 0으로

매끄러운 길에서는 (Δx)²이 Δt보다 한 차원 더 작아서 버려도 되는 거였네요. 이게 보통 연쇄법칙의 비밀!

초파리 연구원

「매끄러운 길」 x(t) = t에서는 맞아. 브라운 운동에서도 그럴까?

하루 편 실험 — 매끄러운 길의 2차 조각

풀이 — 한 걸음씩

  1. Δt = 0.5: 2차 조각 0.25, Δt로 나누면 0.5 — 아직 커요.
  2. Δt = 0.01: 2차 조각 0.0001, Δt로 나누면 0.01.
  3. Δt = 0.001: Δt로 나누면 0.001 → 0으로 사라져요.
  4. 매끄러운 길에서는 (Δx)² ≈ (Δt)²이라 버려요. 그래서 보통 연쇄법칙에는 1차 조각만 있어요.
이 단계의 한계 — 이 결론은 Δx가 Δt에 비례하는 「매끄러운 길」에서만 맞아요. 브라운 운동은 ΔW가 √Δt 크기라서 (ΔW)²이 Δt 크기로 남아요.

2단계 · 브라운 운동에서는 2차 조각이 남는다 — d(W²) = 2W dW + dt

방법: (dW)² = dt일상: 자갈길 연비
박사

상황 질문 — 자갈길을 달리면 매끄러운 도로보다 기름이 더 들어요. 위아래 흔들림 하나하나는 작지만, 그 「제곱」이 쌓이면 무시 못 할 양이 되거든요. W² 에서도 같은 일이 생길까요?

왜 이 방법을 쓰나

  1. 문제 상황: 브라운 운동의 함수 f(W)의 변화를 정확히 계산하고 싶어요.
  2. 앞 방법의 한계: 보통 연쇄법칙대로 d(W²) = 2W dW 라고 하면, 실제 W² 의 변화와 시간만큼 어긋나요.
  3. 해법: 2차 조각 ½f″(ΔW)² 을 버리지 않고, (ΔW)² 의 합이 dt로 남는다는 05장 규칙을 써요. 그러면 df = f′ dW + ½f″ dt.
쉽게 말하면 — 흔들림 제곱이 쌓인 만큼, 시간에 비례하는 덤이 붙는다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

원자료의 df = (fₜ + μfₓ + ½σ²fₓₓ)dt + σfₓ dW 는 너무 길어요. 어디서부터 읽어요?

학교 수학으로 보면: 곱셈 공식 2차 조각에서 시작해요. ½f″(dX)² 에서 (dX)² = (μdt + σdW)² = σ²(dW)² + (아주 작은 것) = σ²dt. 그래서 덤이 ½σ²f″ dt.

식 조각읽는 법뜻
fₜ dt + fₓ dX보통 연쇄법칙 부분시간 변화 + 값 변화에 대한 1차 조각
½fₓₓ (dX)²2차 조각보통 미적분에서는 버리던 부분
(dX)² = σ²(dW)² = σ² dt이토 규칙dt·dt, dt·dW는 0, dW·dW만 dt로 남음
+ ½σ²fₓₓ dt이토의 덤원자료의 빨간 부분
숫자로 한 번 해 보기

f(W) = W², μ = 0, σ = 1: f′ = 2W, f″ = 2

d(W²) = 2W dW + ½ × 2 × dt = 2W dW + dt

0~1에서 더하면 W(1)² = 2∫W dW + 1 → ∫W dW = ½(W(1)² − 1) (07장 답과 같음)

평균: E[W(1)²] = 0 + 1 = 1 ✓ (06장의 「저절로 오르는 몫 t」)

조수 하루 (수강생)

07장 ½t, 06장 W² − t, 05장 이차변동이 전부 이 덤 하나였어요! 이제야 다 연결돼요.

일상으로 치면

자갈길에서는 작은 흔들림이 끊임없이 쌓여 「달린 시간에 비례하는」 추가 연료가 들어요. 흔들림의 방향(위·아래)은 상쇄돼도, 흔들림의 제곱은 상쇄되지 않아요.

확률해석에서는

이토 공식: dX = μdt + σdW 이면 df(X, t) = (fₜ + μfₓ + ½σ²fₓₓ)dt + σfₓ dW. 원자료 오른쪽 「Stochastic chain rule」과 「The extra second-derivative term comes from quadratic variation」이 이것이에요.

X1 편 실험 — W² 변화의 두 조각

풀이 — 한 걸음씩

  1. 검은 막대(실제 W(1)²)는 파란 막대(1차 조각)와 빨간 막대(2차 조각)의 합이에요.
  2. 매끄러운 길이었다면 조각을 늘릴수록 빨간 막대가 0으로 줄어야 해요.
  3. 브라운 운동은 조각을 4096개로 늘려도 빨간 막대가 1(= t) 근처에 남아요.
  4. 그래서 d(W²) = 2W dW + dt. 보통 연쇄법칙(2W dW)에 덤 dt가 붙어요.
이 단계의 한계 — 「(dW)² = dt」는 하나하나의 조각이 정확히 Δt라는 뜻이 아니라, 많이 더했을 때 합이 시간에 모인다는 뜻이에요(05장). 짧게 쓴 「계산 규칙」으로 이해하세요.
박사의 해석 — 토론 판정: X1(덤 편) 승. 하루 편의 보통 연쇄법칙은 매끄러운 세계에서만 맞아요. 이토 공식은 「보통 연쇄법칙 + 흔들림 제곱이 만든 덤」이에요.
원자료의 긴 식을 한 번에 이해 못 해도 괜찮아요. 「(dW)² = dt 때문에 ½σ²f″ dt가 붙는다」 한 문장이면 이 장은 성공이에요.

3단계 · 덤이 평균을 바꾼다 — E[e^W] = e^(t/2)

방법: 덤의 평균일상: 변동성 큰 자산의 복리
박사

상황 질문 — 주가가 매년 평균 0%로 오르내린다면, 10년 뒤 「평균 주가」도 그대로일까요?

왜 이 방법을 쓰나

  1. 문제 상황: 이토 공식의 덤이 실제 숫자(평균)를 얼마나 바꾸는지 보고 싶어요.
  2. 앞 방법의 한계: 「W의 평균이 0이니 e^W 의 평균은 e⁰ = 1」이라는 보통 직감은 틀려요.
  3. 해법: f = e^W 에 이토 공식을 쓰면 d(e^W) = e^W dW + ½e^W dt. dW 항은 평균 0이라, 평균은 ½씩 복리로 불어나 e^(t/2)가 돼요.
쉽게 말하면 — 흔들림이 클수록, 오목·볼록한 함수의 평균은 저절로 움직인다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

왜 평균이 e^(t/2)예요? ½은 어디서 와요?

학교 수학으로 보면: 고등학교 「지수함수」와 「등비수열」이에요. 매 순간 평균이 ½dt 비율로 불어나면, 이자율 ½의 연속 복리 = e^(t/2).

식 조각읽는 법뜻
f(W) = e^W이 의 더블유 제곱f′ = f″ = e^W
d(e^W) = e^W dW + ½e^W dt이토 공식dW 항(평균 0) + 덤(평균을 키움)
E[e^W(t)] = e^(t/2)평균은 이 의 티분의 이 제곱덤 ½ 때문에 연속 복리처럼 증가
숫자로 한 번 해 보기

t = 1: 보통 직감 e⁰ = 1, 이토 공식 e^0.5 ≈ 1.649

모의실험 2만 번 평균 ≈ 1.65

t = 2: e¹ ≈ 2.718

반대로 ln S 에 쓰면: 평균 증가율이 μ에서 μ − σ²/2 로 깎여요(변동성의 「복리 손실」)

조수 하루 (수강생)

평균이 0인 우연인데도 지수함수를 씌우면 평균이 오르다니… 덤이 진짜 숫자를 바꾸네요.

일상으로 치면

+50%와 −50%가 번갈아 오는 투자는 수익률 평균이 0%인데, 100원 → 150원 → 75원으로 돈이 줄어요. 흔들림이 큰 자산은 「평균 수익률」과 「실제로 불어나는 속도」가 달라요. 이 차이를 정확히 재는 게 이토 공식의 덤이에요.

확률해석에서는

f가 볼록(f″ > 0)하면 덤 ½σ²f″ dt가 양수라 평균이 저절로 올라요. 그래서 E[f(W)] ≠ f(E[W])예요. 주가 모형에서 「평균 수익률 μ」와 「로그 성장률 μ − σ²/2」가 다른 이유예요.

심화 — E[e^W(t)] 모의실험

풀이 — 한 걸음씩

  1. 빨간 숫자 1은 「평균의 함수」 e^E[W] 예요.
  2. 파란 숫자(모의실험 평균)는 t = 1에서 약 1.65 — 1보다 커요.
  3. 초록 숫자 e^(t/2)가 모의실험과 맞아요. 이토 공식의 덤 ½e^W dt가 평균을 키운 거예요.
  4. 「함수의 평균」과 「평균의 함수」는 흔들림이 있으면 달라요. 그 차이를 정확히 주는 게 이토 공식이에요.
이 단계의 한계 — 여기서는 W 자체에 지수함수를 씌운 단순한 예예요. 실제 주가 모형(09장)은 표류 μ도 함께 있어요.
박사의 해석 — 변동성이 큰 자산은 「평균 수익률」이 높아도 실제 장기 성장(가운데 값)은 μ − σ²/2 로 깎여요. 레버리지 상품이 장기적으로 녹는 이유를 이 덤으로 설명해요.
